# Звіт з лабораторної роботи №2
**Студент:** Бондаревський Максим

## Мета
Отримати практичні навички створення та налаштування віртуальних машин (EC2 інстансів) у хмарному середовищі AWS на базі операційних систем Windows та Linux.

## Завдання 1: Розгортання Windows-вебсервера
- Створено EC2 інстанс на базі Windows Server.
- Налаштовано роль вебсервера IIS (Internet Information Services).
- Вебсервер успішно запущено та перевірено через localhost.

## Завдання 2: Розгортання Linux-вебсервера
- Створено EC2 інстанс на базі Amazon Linux 2023.
- Здійснено підключення по SSH через термінал macOS із використанням ключа `.pem`.
- Встановлено актуальні компоненти (через оновлення системи): `httpd`, `php`, `php-mysqlnd`, `mariadb105`.
- Завантажено архів із веб-шаблоном сайту з GitLab.
- Файли успішно розпаковано та переміщено в кореневу директорію вебсервера `/var/www/html/`.
- Налаштовано права доступу до конфігураційного файлу та перезапущено службу Apache.

## Висновок
Під час виконання роботи було успішно розгорнуто та налаштовано два типи хмарних вебсерверів. Також було застосовано навички траблшутингу в Linux-середовищі для вирішення конфлікту застарілих пакетів та правильного розміщення файлів сайту. Після завершення тестування інстанси було видалено для оптимізації витрат AWS.
